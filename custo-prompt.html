Metodologia Methodology

Esta página não mede o ChatGPT em produção. Nenhum pedido sai deste site. O simulador estima {% include glossary-term.html id="token" text="tokens" %} de entrada por ~4 caracteres, projeta a saída (teto de {{ data.simulator.chat.output_tokens_cap }} no modo chat; {{ data.simulator.reasoning.output_multiplier.min }}–{{ data.simulator.reasoning.output_multiplier.max }}× no raciocínio) e aplica faixas de Wh por mil tokens de saída, litros de água por kWh (WUE on-site até água da geração elétrica) e preços de API de 2024–25 como ordem de grandeza.

This page does not meter ChatGPT in production. No request leaves this site. The simulator estimates input {% include glossary-term.html id="token" text="tokens" %} at ~4 characters, projects output (capped at {{ data.simulator.chat.output_tokens_cap }} in chat mode; {{ data.simulator.reasoning.output_multiplier.min }}–{{ data.simulator.reasoning.output_multiplier.max }}× in reasoning) and applies bands for Wh per thousand output tokens, liters of water per kWh (on-site WUE through electricity-generation water) and 2024–25 API prices as an order of magnitude.
